# QuizHub 🎯

Welcome to **QuizHub**, an interactive Android Quiz Application! Test your knowledge across multiple categories with a dynamic quiz experience powered by the Open Trivia Database (OpenTDB).

## ✨ Features
- **Dynamic Questions:** Fetches a variety of questions from an open API.
- **Multiple Categories & Difficulty Levels:** Choose what you want to play and how hard it should be.
- **Real-time Timer:** Each question comes with a 10-second countdown timer to keep the excitement going!
- **Instant Feedback:** See the correct answer immediately after choosing an option.
- **Score Tracking:** Keep track of your score and see your final result at the end of the quiz.
- **Multiple Choice & True/False Questions:** Supports different types of questions.
- **Sleek UI:** Clean and responsive user interface for a smooth experience.

## 🚀 Future Improvements
- **User Authentication:** Login/Signup functionality to create personalized profiles.
- **Leaderboard:** Global and local leaderboards to compete with friends and other players.
- **History & Progress Tracking:** Save previous quiz results and track your improvement over time.
- **Multiplayer Mode:** Challenge friends in real-time quiz battles.
- **Offline Mode:** Download question sets for offline play.
- **More Animations:** Enhance the user experience with more interactive and engaging animations.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **Architecture:** Android Native
- **Networking:** Retrofit (for API calls)
- **Data Source:** [Open Trivia Database (OpenTDB)](https://opentdb.com/)

## ⚙️ How to Clone and Run

Follow these steps to run the app on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dev-rajat1/quizApp.git
   ```
2. **Open the project in Android Studio:**
   - Launch Android Studio.
   - Click on `File` -> `Open` and select the cloned `QuizHub` folder.
3. **Sync Gradle:**
   - Wait for Gradle to build and sync the project dependencies.
4. **Run the App:**
   - Connect your Android device or start an emulator.
   - Click the green **Run** button (`Shift + F10`) to build and launch the app.

---
*Note: This app uses a free and open API (OpenTDB), so there are no API keys required to run the project. Just clone, build, and play!*
